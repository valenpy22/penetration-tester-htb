# BreakMySSH - DockerLabs - Very easy

## Summary
The machine runs an outdated version of OpenSSH (7.7) vulnerable to user enumeration (CVE-2018-15473). Valid usernames are discovered via Metasploit, then brute-forced with Hydra to obtain root access.

## Tools
- nmap
- metasploit
- hydra


## 1. Enumeration
### Port Scanning
```sh
sudo nmap -sC -sV -p- -O 172.17.0.2
```

```
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 7.7 (protocol 2.0)
```

OpenSSH 7.7 is vulnerable to user enumeration (CVE-2018-15473) — the server responds differently to valid vs invalid usernames, allowing attackers to enumerate existing accounts.

## 3. Lessons Learned
- OpenSSH < 7.7 is vulnerable to user enumeration (CVE-2018-15473)
- Always check SSH version with nmap — old versions have known CVEs
- User enumeration narrows brute force scope significantly (target root first)
- `rockyou.txt` covers most weak passwords in CTF/lab environments
- Host key errors after container restart are normal — clear with `ssh-keygen -R`

## Flags
- **Credentials:** root:estrella
- **Root proof:** `whoami` → root (direct root, no privesc needed)
