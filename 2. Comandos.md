Apuntes clave
¿Qué es un pentest?

Un pentest (penetration test) es una evaluación de seguridad autorizada donde simulas un ataque real para identificar vulnerabilidades en sistemas, redes o aplicaciones. No es lo mismo que un CTF: aquí no buscas solo una flag, sino entender todo el entorno y documentar cada hallazgo.

Fases de un pentest

Reconocimiento: Recopilar información sobre el objetivo (IPs, dominios, tecnologías, etc.).
Escaneo: Identificar puertos abiertos, servicios activos y posibles vectores de entrada.
Explotación: Aprovechar vulnerabilidades para obtener acceso inicial.
Post-explotación: Escalar privilegios, moverse lateralmente, recopilar información sensible.
Reporting: Documentar todo lo encontrado de forma clara y estructurada.

Apuntes clave
Descubrimiento de hosts
Antes de atacar, necesitas saber qué máquinas están activas en la red.

fping – Escaneo rápido de hosts activos:

fping -a -g {Rango de IP}
-a: Muestra solo las IPs activas.
-g: Especifica que vamos a escanear un rango de IPs.
nmap – Escaneo de ping:

nmap -sn {Rango de IP}
-sn: Realiza un escaneo de ping (sin escaneo de puertos).
netdiscover – Descubrimiento de hosts en la red local:

netdiscover -r {Rango de IP}
-r: Especifica el rango de IPs a escanear.
IP Routing (Acceder a otra IP a la que no tengamos accesibilidad)
A veces necesitas acceder a una red interna desde tu máquina de ataque.

Ver las redes a las que tenemos acceso:

route
Añadir una ruta estática:

ip route add "IP descubierta" via "gateway"

Módulo 2 – Reconocimiento y Escaneo con Nmap
¿De qué va este módulo?
Nmap es tu herramienta estrella. Aquí aprendes a usarla para descubrir puertos abiertos, identificar servicios, detectar versiones y sistemas operativos, y lanzar scripts de reconocimiento.

Objetivos del módulo
Dominar los tipos de escaneo de Nmap (TCP, SYN, UDP, etc.).
Aprender a detectar servicios y versiones.
Usar scripts NSE para enumeración avanzada.
Interpretar correctamente los resultados de Nmap.
Apuntes clave
Detección de sistema operativo
nmap -Pn -O "IP"
-Pn: Ignora la detección de host (útil si el host bloquea ICMP).
-O: Detecta el sistema operativo.
Escaneo rápido de Nmap
nmap -sC -sV "IP"
-sC: Utiliza scripts básicos de reconocimiento.
-sV: Detecta versiones de servicios.
Escaneo completo de Nmap
nmap -sCV -p- "IP" -oN escaneo_completo.txt
-sCV: Combina -sC y -sV.
-p-: Escanea los 65535 puertos.
-oN: Guarda el resultado en un archivo de texto.
Comprobación de vulnerabilidades con Nmap
nmap --script=servicio-* -p"puerto del servicio" "IP"
Ejemplo:

nmap --script=ftp-* -p21 "IP"
Checklist rápida
✅ Sé hacer un escaneo completo de puertos con Nmap.
✅ Entiendo la diferencia entre -sS, -sT y -sU.
✅ Uso -sC y -sV por defecto en mis escaneos.
✅ Conozco los scripts NSE más útiles para enumeración.

¿De qué va este módulo?

Objetivos del módulo

Apuntes clave
SMB (Server Message Block)
SMB es un protocolo de compartición de archivos muy común en redes Windows.

Comprobación de NULL SESSIONS:

smbclient -L "server"
smbclient \\\\\\\\$ip\\\\recurso
-L: Muestra los recursos compartidos.
Comprobación de vulnerabilidades de SMB:

nmap --script=smb-vuln* -p139,445 "ip"
MySQL
Si encuentras MySQL abierto, puedes intentar conectarte y enumerar bases de datos.

Conectar a MySQL:

mysql --user=root --port=13306 -p -h "ip"
-p: Solicita contraseña.
-h: Especifica el host.
Comandos básicos dentro de MySQL:

SHOW databases;
SHOW tables FROM "nombre de la bbdd";
USE "nombre de la bbdd";
SELECT * FROM table;

Módulo 4 – Fundamentos de Hacking Web
¿De qué va este módulo?
Las aplicaciones web son uno de los vectores de entrada más comunes. Aquí aprendes a enumerar directorios, buscar vulnerabilidades web básicas (SQLi, XSS, LFI, RFI) y usar herramientas como Gobuster, Burp Suite y sqlmap.

Objetivos del módulo
Enumerar aplicaciones web: tecnologías, directorios, archivos.
Identificar y explotar vulnerabilidades web comunes.
Usar Burp Suite para interceptar y modificar peticiones.
Automatizar ataques con sqlmap.
Apuntes clave
Recomendaciones para el análisis de aplicaciones web
Revisa toda la página y el código fuente.
Lee cada página, busca emails, usuarios, información sensible.
Una vez encontrada la versión del sistema, busca en Google exploits, CVEs, etc.
Utiliza whatweb o Wappalyzer para identificar tecnologías.
Realiza descubrimiento de directorios y archivos.
Descubrimiento de directorios con Gobuster
gobuster dir -u "ip" -w /usr/share/wordlist.txt -t 30
-u: URL o IP a analizar.
-w: Ruta del diccionario.
-t: Número de hilos (más hilos = más ruido).
Descubrimiento de archivos con extensiones
gobuster dir -u "ip" -w /usr/share/wordlist.txt -t 30 -x .txt,.php,.js
-x: Extensiones a buscar.
Inyección SQL automática con sqlmap
sqlmap -u <url>
sqlmap -u <url> -p <parámetro>
sqlmap -u <url> --tables
sqlmap -u <url> -D <nombre de la BBDD> -T <Nombre de la tabla> --dump

Módulo 6 – Escalada de Privilegios
¿De qué va este módulo?
Conseguir acceso inicial está bien, pero muchas veces necesitas ser root o administrador para completar el objetivo. Aquí aprendes a escalar privilegios en Linux y Windows.

Objetivos del módulo
Identificar vectores de escalada de privilegios en Linux y Windows.
Usar herramientas de enumeración automática (LinPEAS, WinPEAS, etc.).
Explotar configuraciones inseguras, permisos mal configurados, tareas programadas, etc.
Apuntes clave
Enumeración de permisos sudo
Lo primero que debes hacer al obtener acceso a un sistema es verificar qué comandos puedes ejecutar con sudo.

sudo -l
Muestra los comandos que el usuario actual puede ejecutar con sudo.

Buscar binarios SUID
Los binarios con el bit SUID activado se ejecutan con los permisos del propietario (normalmente root), lo que puede permitirte escalar privilegios.

find / -perm -4000 -type f 2>/dev/null
Busca todos los archivos con permisos SUID en el sistema.

Escalar privilegios con sudo + find
Si tienes permisos sudo sobre el comando find, puedes usarlo para ejecutar una shell como root.

sudo find . -exec /bin/bash \; -quit
Ejecuta una shell bash con privilegios de root.

Escalar privilegios con sudo + vim
Si tienes permisos sudo sobre vim, puedes ejecutar comandos desde dentro del editor.

sudo vim -c ':!/bin/bash'
Abre vim y ejecuta una shell bash como root.

Verificar que eres root
Después de escalar privilegios, siempre verifica tu usuario actual.

whoami
id
whoami muestra el nombre del usuario actual. id muestra el UID, GID y grupos.

Buscar flags
Una vez que eres root, busca las flags del sistema.

find / -name "*flag*" 2>/dev/null
Busca archivos que contengan "flag" en su nombre.

Leer hashes de contraseñas
Si eres root, puedes leer el archivo /etc/shadow que contiene los hashes de las contraseñas de los usuarios.

cat /etc/shadow
Muestra los hashes de contraseñas. Puedes intentar crackearlos con John the Ripper o Hashcat.

Password Cracking con John the Ripper
A veces encuentras hashes de contraseñas que necesitas crackear para escalar privilegios.

john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
Usa el diccionario rockyou.txt para crackear los hashes del archivo hash.txt.

Checklist rápida
✅ Conozco los vectores de escalada más comunes en Linux (SUID, sudo, cron, etc.).
✅ Conozco los vectores de escalada más comunes en Windows (servicios, permisos, tokens, etc.).
✅ Uso LinPEAS y WinPEAS para enumeración automática.

Módulo 7 – Pivoting y Redes Internas
¿De qué va este módulo?
A veces, la máquina que comprometes tiene acceso a otras redes internas. Aquí aprendes a usar esa máquina como punto de pivote para acceder a sistemas que no son directamente alcanzables desde tu máquina de ataque.

Objetivos del módulo
Entender qué es el pivoting y cuándo usarlo.
Configurar túneles SSH y port forwarding.
Usar herramientas como Chisel, sshuttle y proxychains.
Apuntes clave
Túneles SSH / Port forwarding
El port forwarding se utiliza para redirigir el tráfico de un puerto específico hacia otro desde la misma o una red distinta. Es decir, un túnel SSH nos permite acceder a un puerto que está activo en la máquina víctima.

Ver puertos activos en la máquina víctima:

netstat -tuln
-t: Muestra las conexiones TCP.
-u: Muestra las conexiones UDP.
-l: Muestra los puertos en modo escucha.
-n: Muestra los números de puerto.
Crear un túnel SSH (Local Port Forwarding):

ssh -L 4545:127.0.0.1:8888 user@"ip_víctima"
De esta manera, el puerto 8888 de la máquina víctima (al cual no teníamos acceso directo) estará disponible en nuestra máquina en 127.0.0.1:4545.

Apuntes clave
Fuerza bruta con Hydra
Es posible que en algún momento necesites hacer un ataque de fuerza bruta a un servicio, como SSH, FTP, etc.

hydra -L usuarios.txt -P contraseñas.txt "ip" ssh -s 22
hydra -L usuarios.txt -P contraseñas.txt telnet://"ip"
-L: Archivo con posibles usuarios.
-P: Archivo con posibles contraseñas.
-s: Puerto destino (ej: 22 para SSH).
Estrategia de examen
Lee bien las preguntas: A veces la clave está en entender exactamente qué te piden.
Responde las preguntas dinámicas inmediatamente: Si reinicias la máquina, la respuesta puede cambiar.
Haz descansos: No te quedes atascado más de 1 hora en un mismo punto. Descansa, despeja la mente y vuelve.
Documenta todo: Anota cada comando, cada hallazgo, cada ruta. Te servirá para volver atrás si te pierdes.
