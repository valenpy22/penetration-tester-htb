# Host 7 - 192.168.0.51

> **Red interna.** Este host pertenece al segmento `192.168.0.0/24`, al que no se llega directamente desde Kali. Se alcanza **pivotando** a través del host dual-homed WINSERVER-03 (`192.168.100.55`), agregando la ruta desde Meterpreter con `run autoroute -s 192.168.0.0/24` (o el comando `route`).

Escaneamos esta IP a través del pivote, sobre un conjunto de puertos comunes:

```sh
nmap -sS -sV -p 21,22,80,135,139,445,3306,3389,5432,5985,8080,10000 192.168.0.51
```

## Explotación — Webmin 1.920 (puerto 10000)

El servicio relevante es **Webmin 1.920** sobre el puerto `10000`, una versión conocida por ser vulnerable a **RCE**. Explotando esa vulnerabilidad obtenemos ejecución de comandos en el host y conseguimos la flag:

```
7a8cb18f24dd41a58b4a6cce55c2e9f2
```

## Resumen de la cadena de ataque

```
Pivote vía WINSERVER-03 (autoroute hacia 192.168.0.0/24) → nmap a 192.168.0.51
     → Webmin 1.920 (puerto 10000) → RCE → flag
```

## Lecciones clave

- Para alcanzar la red interna hay que **agregar la ruta** (`autoroute` / `route`) a través del host dual-homed antes de escanear.
- **Webmin 1.920** es una versión históricamente vulnerable (RCE): identificar la versión en el banner de MiniServ marca el vector directo.
